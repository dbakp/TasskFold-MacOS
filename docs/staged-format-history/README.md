# Staged format repairs and task-history review

The native task-copy repair path now carries reviewed format choices into history matching. A draft stores only bounded operation metadata and partial identity/lifecycle choices. Closing and reopening obtains a fresh authorized task/copy comparison and format preview, then rebuilds the history catalog from exact ephemeral source data. Task content never becomes a replacement tree in the journal.

The catalog binds the preparation to the same account, origin, workspace, session, access epoch, snapshot, root and review digest. Its original task copy must match lexically, preserving unknown JSON numbers and strings. A different source/snapshot or altered format list cannot silently reuse history matches. No history is matched automatically.

A Format repairs section keeps the staged changes visible. Editing those repairs asks for confirmation before clearing history choices; Cancel retains them. The repairs themselves survive the return to structure review. Identity, lifecycle and retirement controls preserve the full format list. Previewing, editing history choices, closing and relaunching retain the combined review; the final request includes the exact format list and existing mapping consent.

## Evidence scope

`verification.json` records current owner-specific Core/native/build outcomes and exact source hashes. `native-phone.json` distinguishes the iPhone control journey from its real PostgreSQL actor/session channel; native HTTP Auth and hosted acceptance are separate. Fixtures use only synthetic tasks, preserve prior synthetic app data by manifest-checked renames, and remove their owned services. Normal app/source flags are unchanged.

The task-copy path is the new native scope. A malformed saved snapshot/record copy needs a separate source-format preview interface. An actively restored older structure still needs its distinct current-access review and atomic adoption/custody action; this screen does not clear restoration fences or expose hidden retained copies. Wider shared custodians, file/audio/discussion/history lifecycle, Mac/iPad/large-text/speech acceptance and prior Px deferrals remain open. No normal installed update or hosted activation is claimed here.
