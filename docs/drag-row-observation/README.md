# Dated rows stop observing finger movement · 7 November 2026

The mobile dated row wrapper read the entire observable drag session to decide whether to collapse, hide or add a gap. That session includes finger position and is updated for each pointer event, invalidating every row even when its appearance stays identical. The existing observation-isolation comment promised more than the code delivered. A signed current-source iPhone Simulator baseline with 124 synthetic tasks confirms 1,494 row-wrapper body evaluations during each 15-update drag, despite only one target-slot change.

`DayDragController` now publishes a separate equatable row-session projection containing only task identity, lift height, dragging/settling phase and collapse state. The full session still drives the floating card and ordinary gesture engine. A changed finger position does not write the row projection; actual lift/settle/end/cancel changes still do. Row visibility, gap height, phase and DayEnd read that projection. Target-slot changes can still reevaluate the row wrappers. This adds no persistent memo, row cache, geometry estimate, task-schema or durable writer change. The existing eager geometry, pinned headers, drag source/workspace checks, priority rules and viewport handling stay intact.

The same actual production-list journey now records 1,494 → 249 row-wrapper evaluations on the first drag; both before/after gesture records are retained in verification.json. Each gesture still uses one source read and one target-slot change. Measurements include initial lift work up to durable commit, use debug (-Onone) builds and fixture-only counters, and exclude post-commit settling. They establish reduced UI invalidation work in this scope, not optimized-release timing, physical FPS or whole-list smoothness.

Both signed runs accept two actual overdue-to-Today drags, saved date/field verification, exact task restoration after each real Undo, and four Today/Upcoming navigation switches. The final run also accepts two vertical scrolls beyond the original first row and confirms every saved table is unchanged by scrolling. The retained screenshots show the original and scrolled larger-list layouts; app runtime warnings are empty. Future tasks are included in Upcoming, while Today contains 83 tasks including the overdue sample. Baseline source reconstruction is verified against the exact built source aggregate and UI-test fingerprints; baseline-instrumentation.patch reproduces the measured legacy observation from its recorded base.
