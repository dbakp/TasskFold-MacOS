# Child-only bulk completion from the task list

Updated 31 October 2026. This is scoped acceptance inside the disabled independent-subtask migration; the broader curated checkpoint remains **To build**.

## Behavior

Select 1–32 independent children, freeze their observed paths and completion cohorts, read each current root, and stage one durable atomic group. No member is staged if any selected member fails preparation. Only a confirmed group offers whole-selection Undo. A lost response retains the original request and offers Review; Retry reuses that request. Recovery can check/stop an uncertain group, review current children, Undo the original confirmed group, or save a reviewed replacement after durable closure. Titles appear only from current authorized reads.

The Mac uses its existing inspector, list feedback and Command-Z. iPhone/iPad use selection mode and the existing confirmation toast. Child rows remain available while selecting in the gated iOS outline; toolbar selection records include those visible children. Mixed root/child selections refuse without a partial legacy write.

All child journals share an account process lock. Admission reads the existing encrypted journals inside that lock: pending groups block overlapping single/field/structure/transfer/adoption/repair writes and private hierarchy drafts; those pending actions/drafts block a new group. Unrelated roots are allowed. Corrupt storage refuses admission without replacing files. Metadata-only outcome checks remain available when a write is blocked.
