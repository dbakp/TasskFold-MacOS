# Task-row note and link readings — 6 November 2026

Task rows now reuse their existing compact note summary or full iPhone accessibility text while its exact source and workspace/session/access scope stay current. Each body requests the preview once. The cache retains at most 128 readings and 8 MiB of source/result UTF-8 content; oversized readings are not retained, and least-recently-read entries are evicted. This is a text-content budget, not a total heap-allocation claim. Account generation, unreadable storage, access-mask and workspace-read revision changes clear retained text. Empty and changed same-ID notes cannot return an outdated preview. No cache is written to disk and preview text is never a save source.

Each rendered title/preview has one source-bound detected-link reading. iPhone attributed text and accessibility grouping share its matches. Grouping now follows links actually present in the rendered preview, instead of scanning hidden note text on every redraw. Mac LinkText reuses the row's detected matches, checks exact current source bytes and falls back to fresh detection if they differ; indices always travel with their own source string. Existing scheme/destination rules, metadata-title lookup, styling and Mac pointer behavior are unchanged. No new network request path is added.
