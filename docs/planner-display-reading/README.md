# One reading per day-planner render

The summary, capacity wording, overlap hint, initial scroll target, all-day rows and timeline previously reread the same expensive derived values separately. The native planner now prepares one ephemeral PlannerDayReading per render and shares it between those consumers. Agenda mode omits graphical lane layout. It is rebuilt from the current productive reading, events, day, calendar/time zone and working hours. No workspace-spanning display cache or edit authority is retained; current scheduling/drop/save/Undo admission is unchanged.

Display rows and productive-capacity work remain distinct. In particular, heading context and unaddressable legacy children keep their existing readable-display versus partial-capacity semantics. The new reading delegates to the existing domain functions once per consumer category, preserving civil-day/DST clipping, unknown estimates, overlap layout and calendar event ordering.
