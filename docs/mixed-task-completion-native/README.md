# Combined task and subtask selection

31 October 2026. A usable, gated app workflow now connects the previously server-only transaction to both independently owned clients.

Select a parent task and an independent subtask together, complete or reopen them atomically, and Undo the whole confirmed selection. Mac uses its existing bulk inspector and Command-Z; iPhone/iPad use selection mode and confirmation feedback. An uncertain response offers Review instead of claiming success. The encrypted saved request survives quitting; retry keeps its original identity and cannot duplicate the operation. Account recovery also permits metadata-only checks and terminal closure. Pending groups participate in the existing cross-operation admission rules.

The server derives Undo from immutable receipts, restores the certified completion state and removes only untouched recurring successors. Changed successors or stale members refuse the whole Undo. Provisional recurring-copy retirement permits a later fresh completion without reviving genuinely deleted generations. All effects and receipts roll back together. Client confirmations validate identities, complete ordered membership, clocks and counters; saved data uses the account-bound encrypted vault and scope fences.
