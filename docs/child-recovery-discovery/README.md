# Saved subtask recovery when features are paused

Updated 31 October 2026. This closes the paused-feature discovery gap recorded in the prior bulk-list milestone. The broader independent-subtask migration remains **To build**.

Mounted Account/recovery screens now discover all seven saved-action families through the existing encrypted journals: fields, individual completion, completion groups, hierarchy, transfers, adoption and repair. Hierarchy discovery includes private drafts and content-removal records. It does not depend on write rollout flags, does not send requests, and publishes only a set of family names bound to the full account/backend/workspace/session/access scope. Unreadable storage keeps its recovery link available; discovery does not replace files.

A latest-request ticket and cancellation/scope checks reject late results, including after account changes. An inactive window cannot clear another mounted screen's presence while an authenticated workspace remains available. Modal dismissal refreshes discovery. This is deterministic coordination coverage, not a complete native background/multi-window audit.
