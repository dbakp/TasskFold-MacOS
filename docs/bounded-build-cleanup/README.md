# Bounded cleanup under storage pressure

Completed builds no longer discard all app objects merely because free storage is between20 and30GiB. In that range cleanup clears disposable index/compilation caches, then removes cheaper SDK/module scratch only as needed to fit the complete selected cache within768MiB. It stops before deleting expensive app objects once the budget is met. Below20GiB it still retires all eligible regenerable scratch. Above30GiB the existing budget-based policy remains. The separate20GiB heavy-build preflight is unchanged.

All previous ownership, marker, symlink, active-builder/app, product/evidence and device protections remain. Removing modules still retires stale Xcode dependency metadata so the next build rescans rather than referencing deleted scan files. Protected products exceeding the budget are reported for review; they are never deleted to satisfy a number. Reports now identify storage pressure and budget in every completed-cache case, and dry runs explicitly avoid claiming actual retirement.

Each independent repository passes20 temporary-filesystem checks, including7 added cases: bounded low-space retention, SDK trim before objects, exact hard-floor boundary, dry-run preservation, active own builder, protected budget excess and honest critical dry-run reporting. Existing critical-pressure deletion, unrelated-builder, symlink, owned-path and shutdown-device protections also pass. Allocation sizes in large-cache tests are mocked to avoid creating large test files.

An actual cleanup on the current iOS/Mac test caches finds both already within budget (329MB and165MB allocated). No additional cache categories need removal. The actual app image and test-plan digests match before and after. Test temporary files clean themselves up. No new SDK build, app update, service/gate, Simulator boot, user-data or Keychain change occurs. Keeping reusable objects is verified; an incremental build-time improvement is not measured or claimed. This is maintenance supporting the full Px work, not another completed app-feature checkpoint.
