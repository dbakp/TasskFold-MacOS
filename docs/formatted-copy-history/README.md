# Reviewed format repairs before history mapping

A malformed saved copy can now be repaired in the same exact reviewed command as its identity/lifecycle mapping. The service derives the repaired tree from the current authorized stored copy and bounded metadata operations; clients never supply replacement source JSON. PostgreSQL retains exact unknown fields and numbers throughout format planning, mapping and immutable original capture.

The existing atomic mapping transaction binds the original copy digest, every format choice, identity/incarnation and lifecycle choice, current history and final proposal. It archives all original copies before staging records and the caller-RLS mirror write. Changed consent, stale access, malformed/oversized choices, nested copy selection and an incomplete format repair refuse without partial writes. Replay and status recovery remain available when mapping is paused. Earlier earned history and recorded completion states remain preserved.

Both owners validate and persist `format_changes` inside a mapped saved-copy choice. Cold command/draft decoding checks nested positions strictly and keeps trees out of metadata storage. An actual service-generated contract exercises source separation, exact archive validation and cold client command parsing.

## Verified scope

See `verification.json` for the independently run personal-account local full-schema Auth/PostgREST checks, each owner's focused Core tests, exact source hashes and advisor findings. Fixtures contain only disposable synthetic tasks and users. Their owned Docker services are removed after each run. The sole existing advisor warning is `pg_net` in the public schema; no new warning is introduced.

The service proves ordinary mapped format repairs can save and recover. It separately verifies that an active restoration with hidden retained copies cannot borrow ordinary task access. When all copies are independently readable, preview explicitly reports restoration custody and the ordinary repair remains unavailable. Failed attempts preserve root/child history, inverse payloads and receipts. The app understands that blocker and explains Undo as the currently available route.

## Still required for editable older restorations

This is a prerequisite, not the final restoration-adoption feature. Connect staged format choices to the native history-review editor and durable partial mapping drafts; implement the distinct reviewed adoption command and its atomic inverse/current-copy custody; preserve file/recording/discussion/history access and quota/lifecycle guarantees; accept Cancel, consent, retry, cold recovery and navigation on the native apps. Do not clear restoration protection or grant access to unproven shadow copies as a shortcut. Shared-workspace formatted mapping remains unaccepted. Cross-device discovery, wider custodians and prior Px acceptance gaps remain tracked in the main plan.

Normal-use gates remain off. No hosted schema, installed app or phone installation changed in this milestone. Existing release/provider/device deferrals remain intact.
