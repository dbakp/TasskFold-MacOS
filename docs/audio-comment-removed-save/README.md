# Recovery after another editor removes a pending audio Save

The controller now keeps a separate existing-only restriction for the lifetime of an authorization. A positively missing lookup changes its current durability, but cannot widen a repeated Retry or a reopened retained Finish into a fresh Save. It also honors a tighter restriction inherited from another retained writer. A changed workspace cannot release this restriction merely because a lookup found no exact journal.

When a previously prepared authorization is absent, the reviewed clip and exact caption stay in memory. The review explains that the pending Save was removed or changed and offers **Save as separate draft**. This explicit choice creates fresh operation/draft IDs with no base, old origin or review-removal claims. The new authorization is retained before the exact old volatile authorization is retired. Other review writers and all old disk versions are left alone. A failure preparing or finishing the new copy still uses that copy's frozen IDs. No automatic checkpoint makes this choice for the user.
