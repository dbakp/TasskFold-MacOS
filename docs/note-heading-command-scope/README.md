# Note heading commands and task priority

The first Command-Option-1 previously changed the synthetic task priority from4 to1 without formatting the note; opening Text style once registered its competing shortcut. Mac now gives the active note a scene-focused Text style command context that replaces task Priority keys, including disabled formatting under Link or Preview. iOS attaches corresponding hardware-key handling to the editor. Explicit Apply and source/session checks remain; no invisible controls or global event tap is added.

The frozen signed Mac product now passes a direct CUA keyboard walkthrough. Fresh H1/H2/H3/body keys work without opening Text style, leaving priority4 and all saved tables unchanged. Bold/Italic/Strikethrough toggle, ordinary Return inserts a line, and Command-Return saves only the expected description. Store Undo/Redo and a separate cold reopen preserve exact task tables. Under Link, Bold/heading/Apply keys leave the draft intact. Escape returns to the outer editor; changed-draft Escape/Discard preserves the entire saved snapshot. The prior isolated fixture is restored exactly and the app closes. See `mac-direct-runtime.json`.

Both original SDK builds pass.
